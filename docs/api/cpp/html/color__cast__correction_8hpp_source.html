3// Adaptive "average neutral" colour-cast correction for the stretched RGB
4// image (Siril's SCNR average-neutral idea, made automatic).
5//
6// Per pixel the green channel is pulled back towards the mean of red and blue,
7// G' = G - amount * max(0, (G - b_g) - max(0, ((R - b_r) + (B - b_b)) / 2)),
8// with b_c the per-channel sky level, so the sky itself is left at its level and
9// only excess above the sky is reduced. The amount is not a user constant and
10// depends on the brightness: the object pixels (blurred luminance clearly above
11// the sky, brightest 1 % excluded, which removes star cores) are split into
12// `brightness_bins` equal-count classes by brightness; per class the amount is
13// chosen so that the median green excess reaches `target_ratio` (capped at
14// `max_amount`; a class whose measured excess is already <= `min_excess` gets
15// amount 0, which protects genuinely green/teal objects such as OIII emission).
16// The per-class amounts are interpolated over the pixel's own
17// brightness (blurred, without the pixel itself), so a cast that differs between
18// faint arms and a bright core is corrected in both without overcorrecting
19// either. brightness_bins = 1 gives a single global amount.
