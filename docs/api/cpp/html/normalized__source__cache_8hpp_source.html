18// Trusted-Run source cache (§T1): no SHA-256 in the hot path. The manifest
19// records file sizes and metadata identity only; a load reads the file and
20// keeps up to `memory_budget_mb`-worth of frames resident in an LRU (plan
21// §30.72 O2). A re-load of a resident index re-stats the file and serves the
22// cached matrix (no read) ONLY if size and mtime are unchanged AND the mtime
23// is strictly older than the instant we last verified it. Any size change,
24// any forward mtime move, a same-tick rewrite, or a stat failure forces a
25// full re-read. Truncation is detected via the size check; in-place content
26// rewrites at the same size are NOT detected (trusted-run contract, §1).
27// `load()` is NOT thread-safe --- for a parallel consumer, give each worker
28// its own instance via the (proto, budget_mb) constructor, which copies the
