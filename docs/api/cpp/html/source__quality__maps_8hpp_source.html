3// Scale-specific source-space quality maps --- milestone M5 of the
4// CFA-forward-drizzle plan (docs/AQMH/aqmh_cfa_forward_drizzle_multiband_
5// implementierungsplan_de.md, sections 13.1-13.5).
6//
7// M5 job (plan 13.1): the legacy compute_source_quality_map() collapses every
8// pyramid scale into one geometric-mean Q-map on a PREWARPED frame. The
9// multiband reconstruction (section 14) needs the per-scale maps kept
10// separate AND expressed in SOURCE coordinates. This module reuses the
11// legacy per-scale math verbatim (via the PerScaleQualityHook added to
12// metrics::compute_source_quality_map) and only changes what is exposed:
13// - q_map : the geometric-mean composite, byte-identical to the
14// legacy path for MONO + all-valid mask (equivalence
15// test), source geometry;
16// - scale_maps / sink: one psi map per computed scale, upsampled to source
17// geometry, streamed one at a time so no more than a
18// single full map plus the running composite is
19// resident (plan 13.3);
20// - artifact_confidence : phi_artifact at the finest computed scale,
21// upsampled to source geometry (1 = clean).
22//
23// The a-trous decomposition, A_artifact / alpha machinery and the multiband
24// mix are M6 scope and are NOT implemented here.
