27// --- Plan 12.4: kernel-induced noise correlation ---------------------------
28//
29// Forward drizzle with a square top-hat droplet of side d = pixfrac *
30// internal_scale (internal pixels) spreads each input sample over several
31// output pixels, so adjacent output pixels are no longer statistically
32// independent. Downstream noise estimators that assume independent per-pixel
33// noise (BGE RMS, PCC star SNR, HMS noise, any SNR map) must scale a naive
34// per-pixel sigma by this factor to recover the true large-aperture noise.
35//
36// Exact, from first principles (no fitted constant): for white input noise
37// the variance of a large-aperture sum is conserved (= sigma_in^2 * N_out),
38// while the naive independent estimate is N_out * sigma_in^2 * S0 / W^2,
39// where W = d and S0 = sum_j overlap([j+0.5 - d/2, j+0.5 + d/2], [0,1])^2.
40// The sigma correction factor is therefore
41// f = W / sqrt(S0) (>= 1; exactly 1 when d = 1, i.e. no correlation).
42//
43// This is the DENSE-input reference case (one input sample per internal
44// pixel). The per-channel forward drizzle samples a given colour sparsely
45// (R/B every 2 native pixels), which correlates output noise MORE; that
46// per-channel refinement is separate and not yet computed here.
47double kernel_noise_correlation_sigma_factor(float pixfrac, int internal_scale);
48
