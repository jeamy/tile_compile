3// Three-way candidate selection for the CFA-forward-drizzle single method ---
4// milestone M6, plan section 15. The three immutable stages are
5// drizzle_uniform --- the safe control
6// drizzle_raw --- B*G_eff*Q_composite, never post-processed (15.1)
7// drizzle_multiband --- the plan-14 fusion
8// measured at ONE fixed star population detected on drizzle_uniform (15.2):
9// candidate_vs_raw does NOT re-detect stars on raw.
10//
11// Selection (15.3):
12// * Raw is chosen over Uniform only if a support / numeric / background-RMS /
13// seam gate is not applicable or is violated. A non-applicable STAR metric
14// alone never rejects Raw.
15// * Multiband is chosen only if EVERY 15.3.4 inequality holds AND support +
16// numerics are fully valid. A non-applicable star metric never counts as
17// positive multiband evidence --- then Raw stays.
18// * Multiband fails -> Raw. Raw fails an applicable / mandatory-N/A safety
19// gate -> Uniform.
20//
21// This module owns only the SELECTION contract and the per-star FWHM
22// statistic (median / p90 / bootstrap CI) that plan 15 adds. Field- and
23// tail-metric measurement at the fixed star set is reused from the existing
24// general validation helpers (measurement only --- no legacy decision code).
25// This module does not itself write `selected_candidate` (16.3): the runner's
26// MULTIBAND phase calls select_reconstruction_candidate() and serialises the
27// result into artifacts/forward_drizzle.json.

43// Half-width (px) of the square patch measured around each star for FWHM.
44inline constexpr int kMultibandValidationStarPatchRadius = 7;
45// A star patch is usable when its centre is finite AND at least this fraction
46// of its pixels are finite; the sparse remaining holes are median-filled.
47// Real OSC working luminance has scattered off-support NaN, so "whole patch
48// finite" rejects every star (M31 2026-09-06: 0 of 250, incl. the control).
49inline constexpr double kMultibandValidationStarPatchMinFiniteFraction = 0.75;
50// boundary_seam_score (plan 15.3, exact form awaits plan confirmation --- 30.42):
51// minimum support-boundary edge pixel count below which the seam metric is
52// reported non-applicable, and the interior-reference stride target (the
53// interior sample is decimated to about this many pixels for speed).
54inline constexpr int kMultibandValidationSeamMinBoundaryPixels = 8;
55inline constexpr int kMultibandValidationSeamInteriorStrideTarget = 40000;
56// The interior-edge locus is derived from a morphologically CLOSED copy of the
57// support mask (dilate-then-erode, square SE of this radius) so that scattered
58// single-pixel off-support dropouts --- endemic to real OSC working luminance
59// (30.47: pre-close boundary was ~20% of supported pixels) --- do not create
60// spurious "boundary". Only the true outer footprint edge and contiguous holes
61// wider than 2*radius survive. The Laplacian is still evaluated on the ORIGINAL
62// field with the on-support-stencil requirement (close selects the locus, it
63// does not fill data). 0 disables closing.
64inline constexpr int kMultibandValidationSeamMaskCloseRadius = 1;
