41// Plan section 9.3 / 8.x: circular dither-spread diagnostic, modulo the 2-px
42// Bayer supercell period, evaluated at 5 native-canvas sites (center + 4
43// corners) using the Rayleigh circular-statistics estimator
44// (theta = pi * (offset mod 2), sigma_circ_px = sqrt(-2 * ln(R)) / pi, R the
45// mean resultant vector length over valid frames at that site). x_p10/y_p10

82// num_workers (<= 1, or 0 => 1) runs the exact serial reference. num_workers > 1
83// processes stripes concurrently (plan §30.72 O1): stripes own disjoint canvas
84// i-ranges and per-i frame-ordered w/w2 sums, so the masks, gate fields and
85// n_eff p10 are bit-identical to the serial run; only the wall time changes.
86// The worker count is additionally bounded by the stripe count and by RAM, and
87// NEVER changes memory.rows / resolved_chunk_rows. gate.workers_used reports the
88// resolved value. resources controls chunk_rows and memory_budget_mb (0 => 512
89// MiB in library; runner resolves 0 from runtime_limits). Production omits full
90// channel counts.
91// Progress callback: called once after each completed band. `done`/`total`
92// count bands (NOT frames --- a band's per-frame loop is not instrumented,
93// per plan §30.72 O1 the band is the smallest unit that stays bit-identical
94// regardless of worker count). Called under an internal lock.
