1// Plan section 11.14 P1/P2 --- authoritative forward-drizzle geometry, built
2// once per (variant, frame) and read back per stripe from a spatial index,
3// replacing the per-stripe full-source re-enumeration in
4// `enumerate_drizzle_stripe_leaf_cells` for LOCAL-WARP frames.
5//
6// Contract (plan 11.14.3 / 11.14.4):
7// * The leaves are produced by the UNCHANGED CPU evaluation
8// (`sample_leaves` -> `subdivide_local` -> `invert_local_source_to_canvas`).
9// No minimax, no re-interpolation of image values. Corner coordinates are
10// stored with their exact `double` bits.
11// * Each source sample passes through `sample_leaves` EXACTLY ONCE per
12// (variant, frame). Subdivision within a sample is still allowed and is
13// counted separately.
14// * The dense footprint (pixfrac == 1) and the drizzle coverage droplet
15// (pixfrac == cfg.pixfrac) are DISTINCT variants. Identical variants
16// (cfg.pixfrac == 1) are deduplicated by identity.
17// * Frame-exclusion rates are finalised by the build; a discarded frame or
18// sample never reappears in a later coverage / profile phase. Chunk height
19// does not influence that set.
20// * Transactional generation commit + per-file checksums + schema/identity
21// verification, like `drizzle_profile_store`. No silent use of an
22// incomplete generation after an abort. Disk pre-flight before writing.
23// * No full-leaf cache of all frames in RAM: the builder streams budgeted
24// record batches to disk; the reader holds only a bounded working window
25// plus the compact per-frame band index.
26//
27// Affine frames are NOT cached: their per-stripe cost is already O(source_px)
28// (the enumerator inverse-maps the stripe corners and bounds the source rows),
29// and they are not "eligible_local_frames" for the P2 acceptance counter.

108// Build the geometry cache for every requested variant. Only local-warp frames
109// are materialised (affine frames stay on the cheap inverse-map path).
110// `memory_budget_bytes` is a floor check on the one-source-row staging buffer.
111//
112// `max_workers` (plan 11.14.5 P3): each (variant, frame) is an independent
113// task --- its own sample_leaves sweep, its own .rows/.leaves files, no shared
114// mutable state. With max_workers > 1 they run on an OpenMP team; results are
115// still assembled into the manifest in deterministic (variant, source_index)
116// order, so the committed store is byte-identical to the max_workers == 1
117// reference regardless of the worker count or scheduling. The per-worker
118// footprint is one source row of leaf records (independent of frame count and
119// canvas height).
120// Progress callback: called once after each COMPLETED (variant, frame) task
121// that was actually a local-warp frame (the cheap non-local tasks are not
122// reported --- there can be hundreds of them and they finish instantly).
123// `done`/`total` count present tasks only. Called under an internal lock, so
124// it is safe to write to a shared log/emitter without its own locking.
125using GeometryCacheProgressFn =
126 std::function<void(std::size_t done, std::size_t total,
127 const std::string &detail)>;

137// Packed-independent public leaf record: one accepted local-warp leaf of
138// one source sample, with the exact double corner bits (ABSOLUTE internal
139// canvas coordinates, same convention as the on-disk LeafRecord --- the
140// internal scale is already applied) and the absolute source coordinate.
141// Forward Drizzle v2 consumes these directly --- no inversion or
142// subdivision is ever re-run on the read path.
143struct DrizzleCachedLeaf {
144 std::uint32_t source_x = 0;
145 std::uint32_t source_y = 0;
146 std::uint16_t channel = 0; // CFA channel index (0 for MONO)
147 std::uint16_t leaf_order = 0; // position inside the sample's leaf list
148 double x[4]{};
149 double y[4]{};
150};

152// Result window of read_stripe_leaves_into: every leaf of one local frame
153// whose canvas y-bbox intersects the requested internal stripe, in
154// canonical (source_y, source_x, leaf_order) order, plus the half-open
155// source bbox of the retained records and the count of distinct covered
156// source samples.
157struct DrizzleCachedLeafWindow {
158 std::vector<DrizzleCachedLeaf> leaves;
159 int source_x0 = 0, source_y0 = 0, source_x1 = 0, source_y1 = 0;
160 std::uint64_t unique_source_samples = 0;
161 // Reused raw row-block staging for the on-disk record bytes
162 // (max_row_record_count()*72 suffices). Cleared and refilled per row
163 // like `leaves`; capacity is preserved across calls.
164 std::vector<std::uint8_t> io_scratch;
165};

167// Verified reader over ONE committed generation.
168//
169// On open it loads and hashes only the per-frame ROW INDEX (`.rows`, a few tens
170// of KiB per frame) and validates structure: schema + algorithm version,
171// per-variant identity, exact expected local-frame population (no missing / no
172// extra / no duplicate), dimension + exclusion-stat consistency, and every
173// row's (offset, count) against the real `.leaves` file length. Leaf RECORDS
174// are NEVER fully resident --- `enumerate_stripe` seek-reads only the row
175// blocks that intersect the requested stripe into a bounded reused buffer.
176//
177// `verify_record_bytes` additionally streams and SHA-256-checks every `.leaves`
178// file on open (correct but O(total store bytes) of I/O --- the caller budgets
179// this); when false, record integrity rests on the `.rows` hash, the structural
180// checks, and the transactional commit chain.
