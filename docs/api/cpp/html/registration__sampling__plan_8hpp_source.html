3// RegistrationSamplingPlan --- data model for CFA-aware forward drizzle.
4//
5// This is the milestone-M0 data model from the implementation plan
6// (docs/AQMH/aqmh_cfa_forward_drizzle_multiband_implementierungsplan_de.md, section 7).
7// It carries the per-frame source->canvas sampling geometry that the forward
8// drizzle reconstruction consumes instead of a pre-warped signal image.
9//
10// The plan (section 7) mandates:
11// * warp convention: the existing registration warp maps canvas -> source
12// (s = W(q)); forward drizzle needs q = W^-1(s).
13// * per-frame stable identity (frame_id + source_index) so a resume can match
14// the plan against the normalized-frame cache and the input manifest.
15// * a canonical plan_hash over the *native* sampling geometry only:
16// internal_scale / output_scale are written to the artifact but are NOT part
17// of plan_hash (they belong to the drizzle-geometry hash domain, section 18.3).
18// * the local (non-affine) warp model coordinates (scale + offsets) so a local
19// model is resumable.

110// --- Affine inversion (plan section 7.2) -------------------------------------
111//
112// Computes the checked 2x3 affine inverse of `canvas_to_source`. Returns false
113// (and leaves `out` untouched) on a singular / non-finite matrix or a
114// determinant outside [det_min, det_max]. The bounds are the existing
115// registration scale-reject bounds squared (a 2x3 affine determinant is the
116// squared linear scale for a similarity transform); callers pass
117// cfg.registration.reject_scale_min^2 and reject_scale_max^2.
118bool invert_affine_2x3(const WarpMatrix& canvas_to_source,
119 float det_min, float det_max,
120 WarpMatrix& out);
121
122// --- Local (non-affine) source->canvas inversion (plan section 7.3) ---------
123//
124// Solves q + d(q) = u for q by the bounded fixed-point iteration
125// q_0 = u ; q_{n+1} = u - d(q_n)
126// where u = inverse(W_global)(s) and d() is evaluated with the persisted
127// model_coordinate_scale / model_offset_{x,y}.
128//
129// Returns true and writes the converged native canvas coordinate to
130// (out_qx, out_qy) on success. Returns false when: the iteration does not reach
131// `tol_px` within `max_iter`, a non-finite value appears, or the point leaves
132// `safety_margin_px` outside the canvas. `max_iter` <= 6 and `tol_px` == 1e-3
133// per the plan; they are parameters here only so tests can exercise edge cases.
134struct LocalInversionParams {
135 int max_iter = 6;
136 float tol_px = 1.0e-3f;
137 float safety_margin_px = 64.0f;
138};
