3// Local energy guard (plan 14.5) and support-aware alpha smoothing
4// (plan 14.7) for the controlled multi-band reconstruction --- milestone M6.
5//
6// Energy guard: per band, on the fixed working luminance, with NO star
7// concentration exception in the first release. window_radius_j =
8// max(3, 2^(j+1)) internal px.
9// scale_raw = max(MAD_window(D_raw,luma,j), background_band_floor_j)
10// energy_ratio(alpha) = MAD_window(D_mixed,luma,j(alpha)) / scale_raw
11// D_mixed,luma,j(alpha) = D_R,luma,j + alpha * (D_profile,luma,j - D_R,luma,j)
12// The binding limit is energy_ratio <= 1.30. If alpha_pre exceeds it, a
13// deterministic six-iteration bisection finds the largest alpha_guarded in
14// [0, alpha_pre] that satisfies the limit. Pixel values and Raw bands are
15// never hard-clipped. Fewer than 25 valid window pixels => alpha = 0 for that
16// band pixel.
17//
18// Alpha smoothing (plan 14.7): after the guard, alpha is blurred with the
19// separable B3 kernel [1,4,6,4,1]/16 ONLY within its own 4-connected support
20// component, then min-capped:
21// alpha_blur = conv(alpha_guarded * support, B3) / conv(support, B3)
22// alpha_final = min(alpha_guarded, alpha_blur)
23// The min cap is mandatory: smoothing may only reduce local evidence, never
24// lift alpha into an uncertain or vetoed pixel. alpha_guarded == 0 stays
25// exactly 0.
