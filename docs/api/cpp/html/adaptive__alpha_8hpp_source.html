3// Adaptive per-band alpha for the controlled multi-band reconstruction ---
4// milestone M6 (plan section 14.4).
5//
6// alpha_j = alpha_cap * A_neff * A_coverage * A_separation
7// * A_artifact * A_registration
8//
9// All factors are in [0, 1]; alpha_j is therefore at most its smallest
10// factor. One alpha_j map is SHARED across R/G/B (plan 14.6); every
11// channel-specific factor uses the conservative min over the active channels.
12//
13// This module computes the two factors that need only the profile planes:
14// A_neff,c = smoothstep(min_effective_samples, full_effective_samples,
15// n_eff_profile,c)
16// A_coverage,c = clamp(profile_support_weight_c / uniform_support_weight_c,
17// 0, 1)
18// with A_* = min over active channels. A_separation / A_artifact /
19// A_registration need per-frame stripe statistics and are supplied here as
20// pre-reduced per-pixel maps (default: 1 everywhere) --- a later M6 batch
21// computes them.
22//
23// Only bands whose profile source is Fine or Medium get a computed alpha map;
24// bands sourced from Raw ignore alpha (plan 14.3) and get an empty map.
