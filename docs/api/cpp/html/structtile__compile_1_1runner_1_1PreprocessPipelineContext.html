Detailed Description

Output bundle from the preprocessing pipeline phases (6): INPUT_FRAMES, CALIBRATION, CFA_CHANNEL_PREP, REFERENCE_SELECTION, REGISTRATION, NORMALIZATION.

These outputs are consumed by QUALITY_ANALYSIS (phase 7) and STACKING.
