3// Profile store manifest --- milestone M3 (plan section 23 M3 acceptance:
4// "Raw wird atomar mit Checksumme persistiert; Uniform-Fallback
5// funktioniert"). A small, plane-file-agnostic manifest that records every
6// persisted profile plane (name, dimensions, file size) plus a canonical
7// hash over the whole manifest, so a resume can fail-closed on a truncated /
8// missing plane file rather than silently reading a bad reconstruction
9// baseline (audit 2026-09-05 finding A6). T1 (trusted run): no SHA-256 in
10// the hot path; v2 uses file size, v1 is read without re-hashing.
11//
12// The plane files themselves are written by the caller (currently
13// io::write_fits_float, which is atomic --- stage + fsync + rename, see
14// fits_io.cpp / plan 30.14). This module only tracks and verifies them.
