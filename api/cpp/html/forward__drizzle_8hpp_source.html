282// Plan §30.75 (P6 SAMPLING_GEOMETRY acceleration): the dense-footprint
283// touched-cell mask for ONE frame over ONE destination stripe.
284//
285// The reference footprint pass runs `rasterize_drizzle_stripe` at pixfrac 1.0
286// with a sink that only records "this internal cell received positive area from
287// some source-pixel square". For an AFFINE frame every unshrunk source-pixel
288// square [sx,sx+1]x[sy,sy+1] maps to a parallelogram, and their union over the
289// whole source is exactly the single parallelogram affine_f([0,W_src]x
290// [0,H_src]) (an affine image of a partition tiles the image). This routine
291// classifies each internal cell of the stripe against that parallelogram P:
292// - exterior (cell lies fully outside one edge of P) -> left untouched;
293// - interior (cell lies at least one mapped-pixel diameter inside every edge
294// of P) -> touched = 1;
295// - boundary (cell straddles or is near an edge of P) -> exact fallback: the
296// same sample_leaves + polygon_rectangle_intersection_area test the
297// reference uses, restricted to the source pixels that can reach the cell.
298// The result is byte-identical to the reference footprint pass by construction.
299//
300// `touched` is resized to internal_width*rows (row-major, stripe-local rows)
301// and every entry is written (0 or 1). LOCAL-warp frames, singular/degenerate
302// affine frames, and `force_exact` delegate to the reference rasterize
303// unchanged. Only used by compute_geometric_coverage; NOT part of the
304// rasterize_drizzle_stripe / CUDA contribution path.
305void dense_footprint_touched_stripe(
306 const registration::RegistrationSamplingPlan &plan,
307 const registration::FrameSamplingTransform &frame, int internal_scale,
308 int y_begin, int rows, std::vector<std::uint8_t> &touched,
309 bool force_exact = false);
