3// Masked, support-propagating a-trous (starlet) decomposition --- milestone M6
4// of the CFA-forward-drizzle plan (docs/AQMH/aqmh_cfa_forward_drizzle_
5// multiband_implementierungsplan_de.md, section 14.2).
6//
7// Shift-invariant a-trous transform with the separable B3-spline kernel
8// h = [1, 4, 6, 4, 1] / 16. For level j (1-based) 2^(j-1)-1 zeros are inserted
9// between kernel taps, so level 1 is undilated, level 2 inserts one zero, etc.
10// Masked convolution propagates a level-specific support (plan 14.2):
11//
12// den_j = convolve(M_(j-1), h_j) (2D, separable)
13// C_j = convolve(C_(j-1) * M_(j-1), h_j) / den_j
14// M_j = M_(j-1) && (den_j >= den_min)
15// D_j = C_(j-1) - C_j, valid only on M_(j-1) && M_j
16//
17// The fully-supported separable kernel sums to 1.0 in each direction, so the
18// fully-supported 2D weight is exactly 1.0 for EVERY level (the dilated kernel
19// still sums to 1). den_min is therefore a fixed fraction of 1.0, identical
20// across levels. It is a versioned constant in the multiband hash domain ---
21// deliberately NOT a config field, so it cannot be tuned without a
22// multiband_config_hash bump (plan 14.2).
