3// Forward-Drizzle-v2 Gate-10 production wiring. Connects the pipeline's
4// predecessor artifacts to the Gate-10 band driver:
5//
6// VerifiedNormalizedSourceCache -> normalized source planes
7// SourceQualityMapCacheReader -> q_composite/q_scale0/q_scale1/
8// q_artifact source planes
9// source_quality_metrics-v1.json -> per-frame sigma_noise
10// global_registration.json -> per-frame sigma_reg (star_residuals
11// rms_px)
12// QualityFrameWeightPlan -> g_eff
13// RegistrationSamplingPlan -> transforms, is_direct,
14// residual_factor, local models
15// DrizzleGeometryCacheReader -> local-warp frame exclusion stats
16//
17// The run plan binds every predecessor identity; a config or predecessor
18// change yields a different plan_hash and the store fails closed.

37// Gate-10 sigma2 input plane (spec wiring_contract/inputs/sigma2):
38// sigma2(y,x) = sigma_noise^2 + (gx^2 + gy^2) * sigma_reg_px^2 + half^2/3
39// with gx/gy the central differences of the normalized source (one-sided at
40// borders; a difference with a non-finite neighbour is taken one-sided, and
41// 0 when no finite neighbour exists). Non-finite/negative inputs produce
42// non-finite plane values, which the kernel maps onto the degraded-sigma
43// contract. Returns source.rows()*source.cols() row-major values.
44std::vector<float> forward_drizzle_v2_sigma2_plane(
45 const Matrix2Df &source, double sigma_noise, double sigma_reg_px,
46 double droplet_half);
47
48// sigma2 for the absolute source rect [y0, y0 + h) x [x0, x0 + w), packed
49// row-major w*h. `window` is a (possibly border-clamped) source read whose
50// absolute origin is (win_x0, win_y0); it must cover the rect plus the one
51// in-bounds pixel ring around it whenever sigma gradients are wanted.
52// Neighbour fallbacks at the true source borders or nonfinite neighbours are
53// identical to forward_drizzle_v2_sigma2_plane on the whole source.
54std::vector<float> forward_drizzle_v2_sigma2_rect(
55 const Matrix2Df &window, int win_x0, int win_y0, int x0, int y0, int w,
56 int h, int source_w, int source_h, double sigma_noise,
57 double sigma_reg_px, double droplet_half);

69// Builds and finalizes the v2 run plan bound to the given predecessor
70// identities. `frame_count` is the participating-frame stream length the
71// provider will serve. Band geometry: `band_rows` core rows per band so one
72// band's workspace stays within min(`host_budget_bytes`/2,
73// `device_budget_bytes`); `band_count` covers [0, native_height). The
74// budgets must be deterministic across resume (the plan_hash binds the band
75// geometry) --- callers pass a NOMINAL device bound, not measured free VRAM;
76// reserve() still verifies the real device per band and a device failure
77// restarts the phase on CPU per the cutover contract. `halo_rows` records
78// the multiband fusion halo for provenance/read accounting (the stored
79// bands are contiguous core rows without padding). Throws invalid_argument
80// on an unsupported output grid (2/2 or output_scale != 1) or a budget that
81// cannot fit a single band row.

95// Nominal per-pixel band-state (dynamic) budget the production planner
96// passes as `device_budget_bytes` when the CUDA path is requested. Fixed,
97// never measured free VRAM: the band geometry is bound into plan_hash and
98// must be identical across resume. CUDA reserve() allocates fixed
99// full-source compatibility/sample/compact-Q buffers (~431 MiB at
100// 3840x2160) and optional cached-leaf storage on top of this cap;
101// bench_m42_v2_spans reserved a total of 2,432,577,804 bytes on the
102// GTX 1660 Ti (observed free 3,658 MiB), so the cap leaves deterministic
103// headroom while remaining resume-stable.
104inline constexpr std::size_t kV2NominalDeviceDynamicBytes = std::size_t{2}
105 << 30;

113// Tranche 8: storage-row intervals covering everything the ragged affine
114// sample list needs. Without sigma, storage equals the active spans. With
115// sigma (`need_sigma_neighbours`) each needed source row r stores the union
116// of its own active span expanded x+-1 and the (unexpanded) active spans on
117// rows r-1 and r+1 --- exactly the cells the central-difference oracle can
118// touch. `row_active_scratch` is source_h ints of workspace. Output rows
119// are ascending source_y, half-open [x_begin, x_end).

124 std::vector<DrizzleAffineSourceSpan> &storage_spans);

126// Tranche 8: build the canonical sample list (ascending (y,x)) from packed

129// storage neighbourhood when `sigma2_present` (identical to
