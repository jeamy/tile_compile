Detailed Description

Shared outputs from CHANNEL_SPLIT, NORMALIZATION, and GLOBAL_METRICS.

The runner keeps these three phases together because normalized frames are immediately reused for global metric extraction and later registration. The context therefore carries both the per-frame normalization scales and the disk-backed cache of normalized frame data.
