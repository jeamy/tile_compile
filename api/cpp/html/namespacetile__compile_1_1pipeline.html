Builds coverage filtered tile grid.

Build a tile grid filtered by frame coverage.

Part of adaptive tile-grid construction based on frame size and configuration; this helper keeps the implementation localized in this translation unit and preserves the surrounding phase, artifact, and error-handling semantics expected by callers.

When canvas_mask is non-empty and the canvas has expanded by more than 10 % relative to original_width × original_height, tiles whose coverage fraction falls below min_tile_coverage_fraction are removed.

Parameters
image_widthWarped canvas width in pixels.
image_heightWarped canvas height in pixels.
tile_sizeTile side length in pixels.
overlap_fractionOverlap between adjacent tiles [0, 0.5].
canvas_maskFlat uint8 mask (row-major). Non-zero = covered. Pass empty vector to skip coverage filtering.
original_widthPre-expansion frame width (for expansion check).
original_heightPre-expansion frame height (for expansion check).
min_tile_coverage_fractionTiles below this coverage are removed (default 15 %).
Exceptions
ReconstructionError(coverage_invariant_violated) if after filtering full_support_tiles / num_tiles < 0.85.
