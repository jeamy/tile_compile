3// Scale-selective ("large-scale") contrast for the stretched RGB image.
4//
5// The single global stretch curve compresses faint, extended sky structure
6// (dust lanes, reflection nebulae, gradients of the sky glow) into a very narrow
7// band above the background level. This stage lifts ONLY that large-scale
8// component and leaves everything at pixel scale untouched, so noise, star
9// profiles and fine detail are not amplified (unlike a local-contrast boost,
10// which acts on fine scales).
11//
12// Mechanism: the luminance is reduced to a star-free large-scale map
13// 1. masked area downsampling to about sigma/6 pixels per cell,
14// 2. a 5x5 median on that grid (removes stars and hot pixels),
15// 3. a masked (normalised) Gaussian of `sigma_px`, so the border of the valid
16// area does not pull the map towards a fill value.
17// The deviation of that map from the sky level (its median over the valid
18// area) is added back, scaled by `amount`:
19// I' = I + amount * (LS(I) - sky) (same delta on R, G and B)
20// `remove_vignette` first subtracts a radially symmetric component (robust
21// polynomial in r^2 about the valid-area centre) from the deviation, so an
22// uncorrected vignette or radial sky glow is not amplified together with the
23// nebula. `chroma_amount` does the same for the colour differences R-G and B-G
24// (G stays unchanged), which brings out large-scale colour structure without
25// touching brightness.
26//
27// Properties: a flat image is left unchanged; pixels outside the valid mask are
28// never touched; values are kept within [0, per-channel maximum of the input];
29// deterministic; no dependence on the frame count. Off by default.
