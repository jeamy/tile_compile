327struct ReconstructionClippingConfig {
328 float clip_sigma_low = 3.0f; // > 0
329 float clip_sigma_high = 3.0f; // > 0
330 // The former plan-11.8 step-8 veto (min_fraction / min_n_eff /
331 // guard_fallback) is not part of the v2 kernel, which has no post-clip
332 // veto: a pixel/channel without source support stays unsupported; below
333 // drizzle.min_clip_contributors candidates (or on reservoir overflow) it
334 // takes the unclipped weighted mean; otherwise the weighted mean of the
335 // sigma-clip survivors. The keys are stripped by the legacy config migration.
336 // Off by default (opt-in): the CFA forward-drizzle kernel runs the sigma/
337 // MAD clip independently per (output pixel, color channel), because R/G/B
338 // are drizzled straight from the raw, still-mosaiced Bayer samples --
339 // each channel has its own native sub-pixel sampling grid (R and B each
340 // ~1/4 of raw pixels, G ~1/2), by design (see
341 // docs/forward_drizzle_v2_zielarchitektur_2026-09-12_de.md). In faint
342 // regions, where per-channel candidate counts sit near
343 // min_clip_contributors, that independence means the surviving frame set
344 // is effectively an independent coin-flip per channel: verified on a
345 // real M42 run, corr(R,B) detail = -0.41 in faint sky (negative --
346 // anti-correlated -- vs. the positive correlation a real, achromatic
347 // source would show), present already in forward_drizzle_multiband_*.fit
348 // before any downstream chroma/luma denoise runs.
349 //
350 // When enabled, a FRAME is rejected consistently across every channel it
351 // contributes to at a given output pixel, instead of each channel
352 // re-deriving its own independent reject decision: each channel still
353 // runs its own weighted-median/MAD clip pass unchanged (per-channel
354 // VALUES are never compared against each other -- R and B sample
355 // physically different sub-pixel positions, so there is no shared value
356 // to test), but a frame is only actually dropped if
357 // shared_frame_rejection_consensus or more of the channels that had a
358 // candidate from it flagged it as an outlier. This targets exactly the
359 // failure mode above (independent per-channel noise in the survivor
360 // *set*) without touching per-channel weights, footprints, sample
361 // counts, or geometry -- so point-source (star) sharpness is
362 // structurally unaffected, and a consensus (not union) rule means a
363 // frame is kept unless most channels that saw it agree it's bad, so a
364 // real per-channel faint-detail difference (not every source is equally
365 // bright in R/G/B) does not itself get treated as an outlier vote.
366 //
367 // Implemented on both the CPU and CUDA forward-drizzle kernels (the CUDA
368 // path splits finalize() into three kernels -- build the per-channel
369 // clip, vote per pixel across channels, reduce -- since the vote step
370 // needs a pixel's channels visible to the same thread; verified
371 // bit-exact against the original single-kernel CUDA path at
372 // shared_frame_rejection_consensus = 1.0, where the vote is a no-op).
373 bool shared_frame_rejection = false;
374 // Fraction (0,1] of the channels that had a candidate from a given frame
375 // at a given pixel that must flag it as an outlier before it is rejected
376 // for ALL of those channels. 0.5 = majority. Lower values reject more
377 // aggressively (closer to "any channel objects" = union); higher values
378 // reject more conservatively (closer to "every channel must agree").
379 float shared_frame_rejection_consensus = 0.5f;
380 // Off by default. After the asymmetric median/MAD clip pass converges,
381 // check the accepted set for a coherent SECOND population the ordinary
382 // bound alone did not separate from the majority (e.g. a subset of frames
383 // with a small but real registration/tracking offset at this exact pixel --
384 // common with wide clip_sigma_low/clip_sigma_high, since those are
385 // deliberately loosened to preserve genuine signal variance and so also
386 // admit a coherent minority more readily). If the largest gap between
387 // consecutive accepted values exceeds bimodal_veto_gap_sigma times the
388 // pass's own MAD and splits off a minority side of at least 2 candidates
389 // holding less than half the accepted weight, that minority is dropped.
390 // Implemented on both the CPU and CUDA forward-drizzle kernels.
391 bool bimodal_veto = false;
392 // Multiple of the clip pass's MAD the largest accepted-value gap must
393 // exceed before the split counts as a coherent second population rather
394 // than ordinary spread. Lower values fire more readily.
395 float bimodal_veto_gap_sigma = 2.5f;
396};
