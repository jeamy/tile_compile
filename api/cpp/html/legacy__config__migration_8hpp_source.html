3// Legacy config migration --- milestone M0 of the CFA-forward-drizzle plan
4// (docs/AQMH/aqmh_cfa_forward_drizzle_multiband_implementierungsplan_de.md
5// section 6.5, decision 2026-09-03 "strip with warning").
6//
7// Applied to the raw parsed YAML *before* it is mapped to config::Config:
8//
9// * `method` (and any reconstruction-selection `engine` key) is a semantic
10// legacy key --- it is REJECTED fail-closed with a ConfigError whose message
11// starts with "UNKNOWN_LEGACY_KEY:". It is never silently stripped or
12// translated (this is the one exception to strip-with-warning).
13//
14// * The removed *structural* blocks (`aqmh`, `pipeline`, `assumptions`,
15// `tile`, `tile_denoise`, `local_metrics`, `synthetic`, `validation`) and
16// removed sub-keys are STRIPPED: a WARN is logged, the stripped path is
17// recorded in the ConfigMigrationReport, and the run proceeds with the
18// cleaned config. The report is written to artifacts/config_migration.json
19// so the strip is auditable.
20//
21// Key *renames* are applied where the value is still meaningful:
22// stacking.common_overlap_required_fraction ->
23// reconstruction.common_overlap_required_fraction.
