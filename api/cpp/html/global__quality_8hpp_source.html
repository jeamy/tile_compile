3// GLOBAL_QUALITY (plan sections 5.2, 11.9): per-frame global quality factor
4// G_quality(f), computed from the source-space CFA analysis proxy (plan
5// 13.2) instead of a prewarped luminance image --- the direct consequence
6// of removing PREWARP from the reconstruction path (plan 11.9's "Herkunft
7// von G_quality(f) nach PREWARP-Entfernung").
8//
9// Reuses metrics::calculate_global_weights_with_stars() EXACTLY as-is
10// ("dieselbe mathematische Definition wie bisher", plan 11.9) on the new
11// input. That function's raw output is w = exp(k * clamp(Q, lo, hi)), an
12// UNBOUNDED positive weight (explicitly documented in metrics.cpp as never
13// normalized to sum 1, since its absolute, frame-count-independent scale is
14// meaningful) --- it does NOT satisfy the plan's "G_quality(f) in [0,1]"
15// contract (11.9), which A_coverage's clamp(w_profile/w_uniform, 0, 1)
16// (14.4) actually depends on: w_profile <= w_uniform pointwise requires
17// G_eff <= 1, and G_eff already multiplies two other [0,1] factors, so a
18// G_quality > 1 on any single frame would silently break that invariant
19// rather than error anywhere. Discovered while implementing this, not
20// stated in the plan text --- see the progress notes for the reasoning.
21//
22// Closed with the minimal, algebraically exact fix: the logistic squashing
23// w/(1+w) = sigmoid(k*Q) applied on top of the *unmodified* legacy weight,
24// rather than re-deriving or duplicating its internals. This preserves the
25// reused formula's frame-set-independent absolute scale (still monotonic in
26// the same underlying Q score) while landing in the open interval (0,1) ---
27// and deliberately never exactly 0 or 1, so it can never be confused with
28// the separate, explicit Q=0 veto semantics (plan 11.9).
