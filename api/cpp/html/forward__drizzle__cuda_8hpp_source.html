120// --- Forward-Drizzle-v2 Gate-6: minimal affine prototype kernel ------------
121//
122// Persistent device workspace implementing the frozen gates 1-5 pipeline per
123// output band: dense scatter into frame-local internal planes (A, B_src,
124// B_geo, optional S2), a fused per-frame fold+accumulate into native-pixel
125// accumulators (full-stream A/B/B2, coverage, support masks, footprint,
126// hash reservoir with per-candidate sigma2), and a band-end finalize kernel
127// running the bit-exact CPU-oracle clip on each pixel's reservoir.
128// No host contribution records, no cudaMalloc/cudaFree after reserve(), no
129// cudaDeviceSynchronize; the only stream sync is the band finalize.
130// Production backend "cuda_v2" (via ForwardDrizzleV2CudaKernel).

151 // inversion bounds check. The workspace band can be shorter than the

175 // records. Exponents follow the plan-11.9 profile contract.
176 bool emit_profiles = false;
177 float fine_quality_exponent = 4.0f;
178 float medium_quality_exponent = 2.0f;

184 // The hash-selected reservoir frames are streamed first as the pilot; after
185 // end_pilot() the pilot's clip bounds are frozen per (pixel, channel) and
186 // every remaining frame's folded candidate is tested against them and added
187 // to the profile/value sums. Requires emit_profiles. Implemented on the CPU
188 // and CUDA kernels.
189 bool full_frame_estimator = false;
190 // See config::ReconstructionClippingConfig::bimodal_veto. Runs once after
191 // each clip pass's bounds are computed, on the pass's accepted set (sorted
192 // by x already): if the largest gap between consecutive accepted values

194 // a minority side of >= 2 candidates with < 50% of the accepted weight,
195 // that minority is rejected -- a coherent second population (e.g. a
196 // registration-drift or trail-contaminated subset of frames) that the

198 // majority when the configured sigma bounds are wide. Implemented on the

202 // CPU host kernel only: OpenMP worker cap for the scatter and fold
