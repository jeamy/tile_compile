13// Optional per-scale observation hook (CFA-forward-drizzle plan M5, section
14// 13.3). Invoked once per computed pyramid scale, immediately after `psi` is
15// formed and BEFORE it is folded into the geometric-mean composite, with:
16// scale_index - pyramid level s (0-based)
17// downsample_factor - legacy convention 1 << (2*s), relative to the frame
18// passed to compute_source_quality_map()
19// psi - the scale's quality map at that scale's (downsampled)
20// grid, values in [0,1], NaN where unsupported
21// psi_src - `psi` already bilinearly upsampled to the full source
22// geometry that compute_source_quality_map() operates on
23// (see upsample_scale_to_source below). The caller needs
24// this same upsample for its own log-accumulation, so it
25// is computed exactly ONCE and handed to both instead of
26// the hook re-deriving it (that redundant second
27// bilinear pass was a measured hot-path duplication,
28// identical LUT/sample-position/support-weighting run
29// twice per scale for no different result).
30// artifact - phi_artifact for that scale on the same grid
31// (1 = clean, 0 = fully artefacted, NaN where unsupported)
32// Default-constructed (null) hook => byte-for-byte identical behaviour to the
33// pre-hook implementation; the legacy prewarped Q-map path passes no hook.
34using PerScaleQualityHook = std::function<void(
35 int scale_index, int downsample_factor, const Matrix2Df &psi,
36 const Matrix2Df &psi_src, const Matrix2Df &artifact)>;

38// Bilinear upsample of one pyramid scale's map to `out_w` x `out_h` (the same
39// half-pixel-centred sample position, clamped 2x2 stencil, and support-
40// weighted normalisation used throughout this file). A source pixel whose
41// interpolation has no finite support, or whose interpolated value is <= 0,
42// comes out as NaN --- a hard zero is never turned into a positive value, and
43// callers can test with std::isfinite/finite() to get the same veto decision
44// accumulate_upsampled_log_psi used to compute inline. Shared by
45// compute_source_quality_map (log-accumulation) and by any per_scale_hook
46// consumer that needs the full-resolution map (e.g. reconstruction's
47// SourceQualityMapCache writer) so the interpolation runs once, not twice.
48Matrix2Df upsample_scale_to_source(const Matrix2Df &src, int out_w, int out_h,
49 int factor);
