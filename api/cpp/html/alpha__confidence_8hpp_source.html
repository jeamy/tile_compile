3// A_separation / A_artifact / A_registration --- the adaptive-alpha
4// confidence factors that need per-frame stripe statistics (plan 14.4).
5// Milestone M6.
6//
7// Status: this is the reviewed, tested PRIMITIVE. Wiring it into the
8// forward-drizzle stripe loop (which must expose, per accepted frame
9// contribution, the geometric weight B_f,c, the K-averaged Q_composite and
10// artifact_confidence, and the frame's registration flags) is a separate
11// integration step --- exactly as apply_robust_clipping() was landed before
12// its drizzle wiring.
13//
14// Definitions (plan 14.4), per target pixel, per active channel c:
15//
16// separation = weighted_p90(q) - weighted_p50(q) weight = B
17// A_separation,c = smoothstep(min_quality_separation,
18// full_quality_separation, separation)
19//
20// a_f,c = K-averaged artifact_confidence_f (per contribution)
21// a_p10,c = weighted_p10(a_f,c) weight = B
22// A_artifact,c = smoothstep(0.25, 0.75, a_p10,c)
23// ; < min_artifact_contributors valid contributions => 0
24//
25// direct_fraction_c = sum_f B * is_direct / sum_f B
26// residual_p20_c = weighted_p20(registration_residual_factor_f) weight=B
27// A_registration,c = min(smoothstep(0.50, 0.85, direct_fraction_c),
28// smoothstep(0.55, 0.90, residual_p20_c))
29//
30// A_* over the frame is min over active channels (done by the caller).
